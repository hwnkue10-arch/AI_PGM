# 🤖 TensorFlow & Python Practice

TensorFlow와 Python을 활용한 머신러닝 및 프로그래밍 기초 실습 프로젝트입니다.

## 📌 프로젝트 소개

이 프로젝트는 Python 프로그래밍과 TensorFlow(Keras)를 이용하여 머신러닝 모델을 구현하고, 데이터 전처리 및 모델 학습 과정을 실습하기 위해 제작되었습니다.

## 📂 실습 내용

### 1. 선형 회귀 (Linear Regression)

- TensorFlow(Keras)를 이용한 선형 회귀 모델 구현
- Sequential 모델 생성
- Dense Layer 구성
- Adam Optimizer 사용
- MSE(Mean Squared Error) 손실 함수 사용
- 학습 데이터 기반 예측 수행

### 2. Python 디버깅

- 리스트 평균 계산
- 내장 함수 `max()` 활용
- 코드 오류 수정 및 디버깅 실습

### 3. MNIST 숫자 이미지 분류

- MNIST 데이터셋 불러오기
- 데이터 정규화(0~255 → 0~1)
- Sequential 모델 구성
- Flatten Layer 사용
- Dense(ReLU) 은닉층 구성
- Softmax 출력층 구현
- 모델 학습 및 성능 평가
