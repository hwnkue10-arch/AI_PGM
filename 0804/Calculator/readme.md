# C++ Win32 GUI Calculator

## 📌 프로젝트 소개

C++과 Win32 API를 이용하여 제작한 Windows GUI 계산기 프로그램입니다.

기본적인 사칙연산 기능부터 시작하여, 계산기 UI 개선과 객체 지향 구조화를 진행하며 실제 Windows 프로그램 형태로 개발하는 것을 목표로 제작했습니다.

---

* Framework/API: Windows Win32 API

# ✨ 주요 기능

## 1. 기본 사칙연산

지원 연산:

* 덧셈 (+)
* 뺄셈 (-)
* 곱셈 (*)
* 나눗셈 (/)

예:

```
10 + 20

결과:
30.00
```

---

## 2. 계산식 표시

현재 입력한 계산식을 별도의 표시창에 출력합니다.

예:

```
10 * 5
---------
50.00
```

계산 과정을 확인할 수 있도록 구성했습니다.

---

## 3. 계산 결과 연속 사용

계산 결과 이후 추가 입력이 가능합니다.

예:

```
7 * 3

결과:
21.00


+ 5 입력

21 + 5

결과:
26.00
```

---

## 4. 추가 버튼 기능

지원 버튼:

| 버튼  | 기능     |
| --- | ------ |
| C   | 전체 초기화 |
| ←   | 입력 삭제  |
| .   | 소수점 입력 |
| ±   | 부호 변경  |
| ( ) | 괄호 입력  |

지원:

* 버튼 색상 변경
* 둥근 모서리 버튼
* 클릭 효과
* Hover 효과
