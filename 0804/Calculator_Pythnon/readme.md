# Python Tkinter GUI Calculator

## 📌 프로젝트 소개

Python과 Tkinter를 이용하여 제작한 Windows GUI 계산기 프로그램입니다.

기본적인 사칙연산 기능부터 시작하여 계산 로직과 UI 구조를 분리하고, Custom Button 구현을 통해 UI 개선과 객체 지향 구조화를 진행했습니다.

C++ Win32 API 계산기 프로젝트의 구조를 Python 환경으로 재구현하는 것을 목표로 제작했습니다.

---

# 🛠 개발 환경

* Language: Python
* GUI Framework: Tkinter
* IDE: Visual Studio Code
* Platform: Windows

# ✨ 주요 기능

## 1. 기본 사칙연산

지원 연산:

* 덧셈 (+)
* 뺄셈 (-)
* 곱셈 (*)
* 나눗셈 (/)

예:

```
10 + 20

결과:
30
```

---

## 2. 계산식 표시

현재 입력한 계산식을 별도의 표시 영역에 출력합니다.

예:

```
10 * 5

결과:
50
```

입력 과정과 계산 결과를 확인할 수 있도록 구성했습니다.

---

## 3. 계산 결과 연속 사용

계산 결과를 다음 계산에 이어서 사용할 수 있습니다.

예:

```
7 * 3

결과:
21


+ 5 입력


21 + 5

결과:
26
```

---

## 4. 추가 버튼 기능

지원 버튼:

| 버튼 | 기능 |
|---|---|
| C | 전체 초기화 |
| ← | 입력 삭제 |
| ± | 부호 변경 |
| . | 소수점 입력 |
| ( ) | 괄호 입력 |

---

# 5. 입력 검증 기능

## 연산자 중복 입력 방지

연속된 산술 연산자 입력을 자동으로 처리합니다.

예:

입력:

```
55 * -
```

결과:

```
55 -
```

또는

```
55 * +
```

입력 시:

```
55 +
```

형태로 마지막 연산자로 변경됩니다.


음수 입력도 지원합니다.

예:

```
5 * -3

결과:
-15
```

---

## 소수점 입력 처리

잘못된 소수점 입력을 방지합니다.

지원:

```
1.25

0.5
```

차단:

```
1.2.3
```
