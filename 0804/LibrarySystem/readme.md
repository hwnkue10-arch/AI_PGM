# 📚 Library Management System

## 프로젝트 소개

C++로 구현한 **콘솔 기반 도서 관리 시스템**입니다.

객체지향 프로그래밍(OOP)을 기반으로 `class`를 활용하여 도서를 관리하고, `vector`를 이용해 여러 권의 도서를 저장하며, `fstream`을 사용하여 파일 저장 및 불러오기 기능을 제공합니다.

---

## 개발 환경

* Language : C++
* IDE : Visual Studio 2022/2026
* Standard Library

  * vector
  * string
  * fstream
  * sstream
  * iostream

---

## 사용 기술

* **Class**

  * Book 클래스
  * Library 클래스

* **Vector**

  * 여러 권의 도서를 동적으로 관리

* **fstream**

  * 도서 정보를 파일에 저장
  * 프로그램 실행 시 파일에서 도서 정보를 불러오기

## 주요 기능

### 1. 도서 등록

* 제목
* 저자
* 출판사

정보를 입력하여 새로운 도서를 등록합니다.

---

### 2. 도서 검색

도서 제목을 입력하여 등록된 도서를 검색합니다.

---

### 3. 전체 도서 목록 조회

등록된 모든 도서 정보를 출력합니다.

출력 정보

* 제목
* 저자
* 출판사
* 대출 상태

---

### 4. 도서 대출

등록된 도서를 대출합니다.

이미 대출 중인 도서는 중복 대출할 수 없습니다.

---

### 5. 도서 반납

대출 중인 도서를 반납합니다.

이미 반납된 도서는 다시 반납할 수 없습니다.

---

### 6. 도서 삭제

도서를 목록에서 삭제합니다.

---

### 7. 파일 저장

현재 등록된 모든 도서 정보를 `books.txt` 파일에 저장합니다.

저장 형식

```text
제목|저자|출판사|대출여부
```

예시

```text
C++ Programming|홍길동|한빛미디어|0
자료구조|김철수|길벗|1
```

* 0 : 대출 가능
* 1 : 대출 중

---

### 8. 파일 불러오기

저장된 `books.txt` 파일을 읽어 프로그램으로 다시 불러옵니다.

프로그램을 종료한 후에도 저장된 도서 정보를 복원할 수 있습니다.

## 객체 구조

### Book

도서 한 권의 정보를 관리합니다.

멤버 변수

* 제목
* 저자
* 출판사
* 대출 여부

주요 기능

* 도서 정보 출력
* 대출
* 반납
* 파일 저장용 문자열 생성

---

### Library

전체 도서를 관리합니다.

내부적으로

```cpp
vector<Book> books;
```

를 사용하여 도서를 저장합니다.

주요 기능

* 도서 등록
* 검색
* 삭제
* 대출
* 반납
* 전체 출력
* 파일 저장
* 파일 불러오기
