# 📚 Python GUI 도서 관리 시스템

## 📌 프로젝트 소개

Python과 Tkinter GUI를 이용하여 제작한 도서 관리 프로그램입니다.

기존 콘솔 기반 도서 관리 시스템을 GUI 프로그램으로 개선하여,
사용자가 화면을 통해 도서를 등록하고 관리할 수 있도록 구현했습니다.

도서 등록, 검색, 삭제, 대출, 반납 기능과 JSON 파일 저장 기능을 적용한
객체 지향 기반 개인 학습 프로젝트입니다.

---

# 🛠 개발 환경

* Language: Python
* GUI Framework: Tkinter
* Data Storage: JSON
* IDE: Visual Studio Code
* Platform: Windows

# ✨ 주요 기능

## 1. 도서 등록

도서 정보를 입력하여 새로운 도서를 등록합니다.

입력 정보:

- 제목
- 저자
- 출판사


동작:

```
제목 입력
↓
저자 입력
↓
출판사 입력
↓
등록 버튼 클릭
↓
도서 목록 추가
```

---

## 2. 전체 도서 목록

등록된 모든 도서를 GUI 화면에서 확인할 수 있습니다.

표시 정보:

| 항목 | 설명 |
|---|---|
| 제목 | 도서 제목 |
| 저자 | 도서 저자 |
| 출판사 | 출판사 |
| 상태 | 대출 가능 / 대출중 |

---

## 3. 도서 검색

검색창을 이용하여 원하는 도서를 찾을 수 있습니다.

검색 방식:

```
제목 부분 검색
```

예:

입력:

```
Python
```

결과:

```
Python Programming
```

---

## 4. 도서 삭제

목록에서 원하는 도서를 선택한 후 삭제합니다.

동작:

```
도서 선택
↓
삭제 버튼 클릭
↓
목록에서 제거
```

---

## 5. 도서 대출

선택한 도서의 상태를 변경합니다.

변경:

```
대출 가능

↓

대출중
```

이미 대출중인 도서는 다시 대출할 수 없습니다.

---

## 6. 도서 반납

대출된 도서를 반납 처리합니다.

변경:

```
대출중

↓

대출 가능
```

---

## 7. 데이터 저장

현재 도서 목록을 JSON 파일로 저장합니다.

저장 파일:

```
books.json
```

저장 데이터 예시:

```json
[
    {
        "title": "Python",
        "author": "Kim",
        "publisher": "Example",
        "borrowed": false
    }
]
```

---

## 8. 데이터 불러오기

저장된 도서 데이터를 다시 불러옵니다.

지원 기능:

- 프로그램 종료 후 데이터 유지
- 기존 도서 목록 복구
