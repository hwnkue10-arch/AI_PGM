# 📚 Python Library Management System

## 프로젝트 소개

Python으로 구현한 **콘솔 기반 도서 관리 시스템**입니다.

객체지향 프로그래밍(OOP)을 기반으로 `class`를 사용하여 도서를 관리하고, `list`를 활용하여 도서 목록을 저장하며, `json` 파일을 이용해 데이터를 저장하고 불러오는 기능을 제공합니다.

C++ 도서 관리 시스템에서 사용했던 구조를 Python 방식으로 변환한 프로젝트입니다.

---

# 개발 환경

* Language : Python
* IDE : Visual Studio Code / PyCharm
* Version : Python 3.x

---

# 사용 기술

## Class

도서와 도서 관리 기능을 객체로 분리하여 구현했습니다.

사용 클래스:

* `Book`
* `Library`

---

## List

C++의 `vector` 역할을 Python의 `list`로 구현했습니다.

C++:

```cpp
vector<Book> books;
```

Python:

```python
self.books = []
```

등록된 모든 도서는 list에서 관리됩니다.

---

## JSON

C++의 `fstream` 파일 저장 기능을 Python의 `json` 모듈로 구현했습니다.

저장 파일:

```text
books.json
```

JSON 형식으로 도서 정보를 저장하여 프로그램 종료 후에도 데이터를 유지할 수 있습니다.

---

# 프로젝트 구조


# 주요 기능

## 1. 도서 등록

새로운 도서를 등록합니다.

입력 정보:

* 제목
* 저자
* 출판사

---

## 2. 도서 검색

제목을 기준으로 원하는 도서를 검색합니다.

---

## 3. 전체 도서 목록

현재 등록된 모든 도서 정보를 출력합니다.

출력 정보:

* 제목
* 저자
* 출판사
* 대출 상태

---

## 4. 도서 대출

도서를 대출 상태로 변경합니다.

이미 대출 중인 도서는 다시 대출할 수 없습니다.

---

## 5. 도서 반납

대출한 도서를 반납합니다.

---

## 6. 도서 삭제

등록된 도서를 삭제합니다.

---

## 7. JSON 저장

현재 도서 목록을 `books.json` 파일로 저장합니다.

저장 예시:

```json
[
    {
        "title": "Python",
        "author": "홍길동",
        "publisher": "한빛",
        "borrowed": false
    }
]
```

---

## 8. JSON 불러오기

프로그램 실행 시 저장된 JSON 파일을 읽어 이전 데이터를 복원합니다.

객체 형태로 다시 변환하여 list에 저장합니다.

* JSON 저장
